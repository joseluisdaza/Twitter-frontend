## 📋 Overview

This repository contains the static frontend for **Chirp** — a Twitter-like social platform. It is built with plain HTML, CSS, and vanilla JavaScript (no framework), keeping the bundle size minimal and the deployment simple.

It is used as a **Git Submodule** inside [joseluisdaza/twitter](https://github.com/joseluisdaza/twitter), mounted at `frontend/`. The CDK stack uploads these files to S3 and distributes them through CloudFront on every deploy.

---

## 📁 Structure

```
Twitter-frontend/
└── dist/
    ├── index.html          # App shell — single HTML file
    ├── app.js              # All application logic (auth, API calls, rendering)
    ├── style.css           # Styles
    └── runtime-config.js   # Auto-generated by CDK — injects the API Gateway URL
```

> **Note:** `runtime-config.js` is generated automatically during `cdk deploy` and should not be edited manually or committed to version control.

---

## ✨ Features

- **Authentication** — Register, login, and logout via AWS Cognito
- **Timeline** — Personalized feed of chirps from followed users, with a refresh button
- **Chirps** — Create, delete, hide, like, and comment on chirps
- **User Profiles** — View profiles, edit display name and bio, see chirp history
- **Search** — Find users by username and follow/unfollow them
- **User Resolution** — Display names are resolved and cached before rendering to avoid raw UUIDs in the UI

---

## 🚀 Local Development

Open `dist/index.html` directly in a browser. You will need a `runtime-config.js` file pointing to a deployed API:

```javascript
// dist/runtime-config.js
window.RUNTIME_CONFIG = { apiUrl: 'https://<your-api-id>.execute-api.us-east-1.amazonaws.com/' };
```

No build step required — all assets are already in `dist/`.
